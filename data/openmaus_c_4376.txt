### #4376 rafitigay [2026-11-05T20:16:25Z]
Well after several days of frustration, I think I got it figured out.

Commit 6371611 addresses this issue with local models, except that fix only kicks in when you are using a local address. It's possible, such as in my case, that you have a local model connected over a vpn, so we were using https. Because of that the items that Commit 6371611 addresses did not kick in.

There needs to be a way to apply the fixes from Commit 6371611 to non local addresses. Like a checkbox.
